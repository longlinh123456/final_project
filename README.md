# DATA1010 Final Project Group A

## Installation

Please install `uv` (follow instructions at <https://docs.astral.sh/uv/getting-started/installation>).

To install the libraries (i.e. when first cloning this repo), run `uv sync`.
Use the virtual environment (located in `.venv`) in this library when developing/running the notebook.

## Committing

Stage changed files before committing.
The commit may fail; this is because the pre-commit hook cleaned the notebook. You should stage the modifications made by the hook and then commit again.
